# Built-in sayings: where each one comes from

The quote widget's built-in sayings (`sayings.rs`) are real quotations. Every line below was checked against the source it links to before it went in: English Wikiquote's sourced sections (never its *Attributed*, *Disputed* or *Misattributed* sections), the public-domain text of the work on Project Gutenberg, or Arabic Wikisource for Arabic originals. Translated works use the translation named in the note, public-domain ones where there is one.

Small typographic changes only: verse line breaks are joined into one line, a sentence taken from a longer passage starts with a capital, and old spellings are kept except where the note says otherwise. Proverbs have no single author or work; the note says where the proverb is attested.

When adding a saying, add it to `sayings.rs` and here, with the link you checked it against, and translate its text, author and work in every catalog in `crates/mandara-i18n/locales/`.
