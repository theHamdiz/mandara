# Mandara artwork

- App tiles: 1024-unit square; tile inset 32, radius 216, primary shoreline stroke 88, rim 8. The main mark was checked at 16 px. Symbolic artwork fills its own 704-unit viewBox.
- Plugin tiles: 512-unit square; tile inset 16, radius 108, primary stroke 28. Use rounded caps and joins, a centered glyph around 112–400, cream `#FFF2D5`, and sand `#FFD58A`.
- Glass: one quiet diagonal gradient, a top-left highlight, a thin inner rim, and a translucent lower shoreline. Keep the glyph dominant. Icons contain no lettering or borrowed project marks; Bluetooth uses two wireless peers.
- Covers: name at the upper left in Inter; a large icon; restrained thematic linework; a floating real panel where supplied. Preserve panel proportions and use a soft shadow. UI appears only in the 21 real captures linked through the catalog; captures never show private data (demo accounts, blurred addresses, or a crop to non-identifying parts). The dock retains its full transparent capture and source corner shape, with no desktop background. The other new covers use illustrations because no suitable isolated capture is available.
- The added cover motifs are `watch` (eye contours), `shelf` (dock rails), `package` (open carton), `hourglass` and `aurora` (flowing contours and a sparkle). System tray and Mini stats reuse `peers` and `bars` respectively. Mini stats is visible in Studio's uncategorized store group; the internal Compositor commands are hidden and have no marketplace art.

The backgrounds were generated separately with the built-in image generation tool. Icons and cover linework are hand-authored vectors. Screenshot sources stay in `../docs/screenshots/`; their interiors are preserved before final color optimization. Studio captures informed the family styling.

The whole pipeline is Rust (`xtask/src/art.rs`): SVGs render with [resvg](https://github.com/linebender/resvg), cover lettering is drawn with ab_glyph from the installed Inter font (`MANDARA_COVER_FONT` overrides), and covers are quantized to a 256-color palette with dithering. Icon PNGs are losslessly optimized.

## Embedded in the binary

`cargo xtask art` turns every built-in plugin's art into the compact set the shell and Studio embed, in [`crates/mandara-ui/assets/plugin-art/<id>/`](../crates/mandara-ui/assets/plugin-art): `icon.png` (128 px, rendered from the SVG), `icon@2x.png` (256 px) and `cover.jpg` (960×540, JPEG quality 82; a PNG when the cover has transparency), plus the generated `index.rs` table. The generated files are committed — they are build inputs. Example plugins in `plugins/examples/` ship their own `icon.png` / `cover.png` inside their package instead.

The embedded-art ceiling is **4.5 MiB (4,718,592 bytes)**, allowing roughly 100 KiB per built-in plugin's icon pair and cover, with headroom for a few more plugins. The 41-plugin set uses **4,292,314 bytes (4.09 MiB)**, leaving **426,278 bytes** of headroom. Cover dimensions and JPEG quality are unchanged.

```sh
cargo xtask art --compose            # render source icons and compose covers (--only ID)
cargo xtask art --compose --out /tmp/mandara-covers  # preview covers without source changes
cargo xtask art                      # rebuild the embedded icons and covers
cargo xtask art --check              # validate everything
```
